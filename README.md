# Generative Art

A simple interactive p5.js prototype about distance, avoidance, and connection in shared public space.

## Run it

Open `index.html` in a browser.

- Move the mouse to control the orange visitor.
- Use the arrow keys or W/A/S/D to control the blue visitor.
- Click to add another black agent.

The sketch is influenced by Erving Goffman's idea of civil inattention, Georg Simmel's writing on urban reserve, and Craig Reynolds' separation steering.
